## Rede

### Arquitetura de rede

* [Network-segmentation-cheat-sheet](https://github.com/sergiomarotco/Network-segmentation-cheat-sheet) - Este projeto foi criado para publicar as melhores práticas de segmentação da rede corporativa de qualquer empresa. Em geral, os esquemas deste projeto são adequados para qualquer empresa.

### Varredura / Pentest

* [Darkmoon](https://github.com/ASCIT31/Dark-Moon) - Plataforma open source de pentest autônomo com IA, auto-hospedável via docker-compose e com servidor MCP, cobrindo web, API, Active Directory e Kubernetes.
* [OpenVAS](http://www.openvas.org/) - OpenVAS é um framework de vários serviços e ferramentas oferecendo uma solução abrangente e poderosa de varredura e gerenciamento de vulnerabilidades.
* [Metasploit Framework](https://github.com/rapid7/metasploit-framework) - Uma ferramenta para desenvolvimento e execução de código exploit contra uma máquina alvo remota. Outros subprojetos importantes incluem o Opcode Database, arquivo de shellcode e pesquisas relacionadas.
* [Kali](https://www.kali.org/) - Kali Linux é uma distribuição Linux derivada do Debian projetada para forense digital e testes de invasão (penetration testing). O Kali Linux vem pré-instalado com vários programas de testes de invasão, incluindo nmap (um scanner de portas), Wireshark (um analisador de pacotes), John the Ripper (um quebrador de senhas) e Aircrack-ng (um conjunto de softwares para testes de invasão em redes sem fio LAN).
* [tsurugi](https://tsurugi-linux.org/) - Distribuição Linux fortemente customizada desenhada para apoiar investigações DFIR, análise de malware e atividades OSINT. É baseada no Ubuntu 20.04 (64-bit com um kernel customizado 5.15.12).
* [pig](https://github.com/rafael-santiago/pig) - Uma ferramenta Linux para forjar pacotes (packet crafting).
* [scapy](https://github.com/gpotter2/awesome-scapy) - Scapy: a biblioteca e programa interativo baseado em python para manipulação de pacotes.
* [Pompem](https://github.com/rfunix/Pompem) - Pompem é uma ferramenta de código aberto, projetada para automatizar a busca por exploits nos principais bancos de dados. Desenvolvida em Python, possui um sistema de busca avançado, facilitando assim o trabalho de pentesters e hackers éticos. Em sua versão atual, realiza buscas nas bases: Exploit-db, 1337day, Packetstorm Security...
* [Nmap](https://nmap.org) - Nmap é um utilitário gratuito e de código aberto para descoberta de rede e auditoria de segurança.
* [Amass](https://github.com/owasp-amass/amass) - O Amass realiza enumeração de subdomínios DNS fazendo raspagem (scraping) do maior número de fontes de dados distintas, força bruta recursiva, crawling em arquivos web, permutação e alteração de nomes, varredura de DNS reverso e outras técnicas.
* [Anevicon](https://github.com/rozgo/anevicon) - O gerador de carga baseado em UDP mais poderoso, escrito em Rust.
* [Finshir](https://github.com/isgasho/finshir) - Um gerador de tráfego "Low & Slow" orientado por corrotinas, escrito em Rust.
* [Legion](https://github.com/GoVanguard/legion) - Framework de testes de invasão de rede de código aberto para descoberta e reconhecimento semi-automatizados.
* [Lonkero](https://github.com/bountyyfi/lonkero) - Scanner de vulnerabilidades web de nível corporativo com mais de 60 módulos de ataque, construído em Rust para testes de invasão e avaliações de segurança.
* [Sublist3r](https://github.com/aboul3la/Sublist3r) - Ferramenta rápida para enumeração de subdomínios para testadores de invasão.
* [RustScan](https://github.com/RustScan/RustScan) - Escaneamento Nmap mais rápido com Rust. Reduz um escaneamento Nmap de 17 minutos para 19 segundos.
* [Boofuzz](https://github.com/jtpereyda/boofuzz) - Motor e framework de testes de fuzzing.
* [monsoon](https://github.com/RedTeamPentesting/monsoon) - Enumeração/fuzzing HTTP interativo muito flexível e rápido.
* [Netz](https://github.com/spectralops/netz)- Descubra más configurações em toda a internet, usando zgrab2 e outros.
* [Deepfence ThreatMapper](https://github.com/deepfence/ThreatMapper) - Apache v2, poderoso scanner de vulnerabilidade em tempo de execução para kubernetes, máquinas virtuais e serverless.
* [Deepfence SecretScanner](https://github.com/deepfence/SecretScanner) - Encontre segredos e senhas em imagens de contêineres e sistemas de arquivos.
* [Cognito Scanner](https://github.com/padok-team/cognito-scanner) - Ferramenta CLI para fazer pentest em instâncias AWS Cognito. Implementa três ataques: criação indesejada de conta, "account oracle" e escalonamento de pool de identidade.

### Monitoramento / Logging

* [BoxyHQ](https://github.com/retracedhq/retraced) - API de código aberto para registro de auditoria (audit logging) de segurança e conformidade.
* [justniffer](http://justniffer.sourceforge.net/) - Justniffer é um analisador de protocolo de rede que captura tráfego de rede e produz logs de maneira customizada, pode emular arquivos de log do servidor web Apache, rastrear tempos de resposta e extrair todos os arquivos "interceptados" do tráfego HTTP.
* [httpry](http://dumpsterventures.com/jason/httpry/) - httpry é um farejador (sniffer) de pacotes especializado, projetado para exibir e registrar o tráfego HTTP. Não se destina a realizar análises em si, mas a capturar, analisar sintaticamente e registrar o tráfego para análises posteriores. Pode ser executado em tempo real, exibindo o tráfego conforme é analisado, ou como um processo daemon que grava em um arquivo de saída. É escrito para ser o mais leve e flexível possível.
* [ngrep](http://ngrep.sourceforge.net/) - ngrep se esforça para fornecer a maioria dos recursos comuns do grep GNU, aplicando-os à camada de rede. O ngrep é uma ferramenta sensível a pcap que permite especificar expressões regulares estendidas ou hexadecimais para coincidir com os dados de carga útil (payload) dos pacotes.
* [passivedns](https://github.com/gamelinux/passivedns) - Uma ferramenta para coletar registros DNS passivamente para auxiliar no tratamento de Incidentes, Monitoramento de Segurança de Rede (NSM) e forense digital geral.
* [sagan](http://sagan.quadrantsec.com/) - Sagan usa um motor 'tipo Snort' e regras para analisar logs (syslog/event log/snmptrap/netflow/etc).
* [ntopng](http://www.ntop.org/products/traffic-analysis/ntop/) - Ntopng é uma sonda de tráfego de rede que mostra o uso da rede, semelhante ao que faz o popular comando top no Unix.
* [Fibratus](https://github.com/rabbitstack/fibratus) - Fibratus é uma ferramenta para exploração e rastreamento do kernel do Windows. Capaz de capturar a maior parte da atividade do kernel do Windows.
* [opensnitch](https://github.com/evilsocket/opensnitch) - OpenSnitch é uma porta GNU/Linux do firewall de aplicação Little Snitch.
* [wazuh](https://github.com/wazuh/wazuh) - Wazuh é uma plataforma gratuita e de código aberto usada para prevenção, detecção e resposta a ameaças.
* [Matano](https://github.com/matanolabs/matano): Plataforma open source de data lake de segurança serverless na AWS.
* [Falco](https://falco.org/) - O projeto cloud-native de segurança em tempo de execução e mecanismo de detecção de ameaças de fato para Kubernetes.
* [VAST](https://github.com/tenzir/vast) - Motor de pipeline de dados de segurança de código aberto para dados de eventos estruturados.
* [Substation](https://github.com/brexhq/substation) - Substation é um toolkit cloud native para pipeline e transformação de dados escrito em Go.
* [Sigma2KQL](https://github.com/Khadinxc/Sigma2KQL) - Um repositório de todas as regras SIGMA convertidas para KQL.
* [Sigma2SPL](https://github.com/Khadinxc/Sigma2SPL) - Um repositório de todas as regras SIGMA convertidas para SPL.
* [TerraSigma](https://github.com/Khadinxc/TerraSigma) - Um repositório de todas as regras SIGMA convertidas para recursos analíticos agendados no Microsoft Sentinel Terraform.

### IDS / IPS / Host IDS / Host IPS

* [Snort](https://www.snort.org/) - Snort é um sistema de prevenção de intrusão de rede (NIPS) e sistema de detecção de intrusão de rede (NIDS) gratuito e de código aberto.
* [Zeek](https://zeek.org/) - Zeek é um poderoso framework de análise de rede, muito diferente do IDS típico que você possa conhecer.
* [zeek2es](https://github.com/corelight/zeek2es) - Uma ferramenta open source para converter logs do Zeek para Elastic/OpenSearch.


* [DrKeithJones.com](https://drkeithjones.com) - Um blog sobre segurança cibernética e monitoramento de segurança de redes.
* [OSSEC](https://ossec.github.io/) - HIDS Open Source Abrangente. Realiza análise de log, verificação de integridade de arquivos, monitoramento de políticas, detecção de rootkits, alertas em tempo real e resposta ativa.
* [Suricata](http://suricata-ids.org/) - Suricata é um motor de Monitoramento de Segurança de Rede, IPS e IDS de Rede de alta performance.
* [Security Onion](http://blog.securityonion.net/) - Security Onion é uma distribuição Linux para detecção de intrusão, monitoramento de segurança de rede e gerenciamento de logs.
* [sshwatch](https://github.com/marshyski/sshwatch) - IPS para SSH similar ao DenyHosts, escrito em Python.
* [Stealth](https://fbb-git.gitlab.io/stealth/) - Verificador de integridade de arquivos quase sem rastros.
* [AIEngine](https://bitbucket.org/camp0/aiengine) - AIEngine é um motor interativo/programável de inspeção de pacotes de próxima geração.
* [Denyhosts](http://denyhosts.sourceforge.net/) - Frustra ataques baseados em dicionário ao SSH e ataques de força bruta.
* [Fail2Ban](http://www.fail2ban.org/wiki/index.php/Main_Page) - Verifica arquivos de log e toma ações em IPs que mostram comportamento malicioso.
* [SSHGuard](http://www.sshguard.net/) - Um software para proteger serviços, além do SSH, escrito em C.
* [Lynis](https://cisofy.com/lynis/) - uma ferramenta open source para auditoria de segurança no Linux/Unix.
* [CrowdSec](https://github.com/crowdsecurity/crowdsec) - CrowdSec é um motor de detecção de comportamentos gratuito, moderno e colaborativo, acoplado a uma rede global de reputação de IPs.
* [wazuh](https://github.com/wazuh/wazuh) - Wazuh é uma plataforma XDR de código aberto usada para prevenção, detecção e resposta a ameaças, protegendo workloads em nuvem, contêineres, virtuais e on-premise.

### Honey Pot / Honey Net

* [awesome-honeypots](https://github.com/paralax/awesome-honeypots) - A lista canônica incrível de honeypots.
* [HoneyPy](https://github.com/foospidy/HoneyPy) - HoneyPy é um honeypot de baixa a média interação.
* [Conpot](http://conpot.org/) - Honeypot para ICS/SCADA. Conpot é um honeypot server side de baixa interatividade para Sistemas de Controle Industrial.
* [Amun](https://github.com/zeroq/amun) - Amun Honeypot baseado em Python de baixa interação.
* [Glastopf](http://glastopf.org/) - Glastopf é um Honeypot que emula milhares de vulnerabilidades para reunir dados de ataques visando aplicações web.
* [Kippo](https://github.com/desaster/kippo) - Kippo é um honeypot SSH de média interação desenvolvido para registrar ataques de força bruta e as interações de shell.
* [Kojoney](http://kojoney.sourceforge.net/) - Kojoney é um honeypot de baixa interação que emula um servidor SSH.
* [HonSSH](https://github.com/tnich/honssh) - HonSSH é uma solução de Honey Pot de alta interação.
* [Bifrozt](http://sourceforge.net/projects/bifrozt/) - Bifrozt é um dispositivo NAT com servidor DHCP para implantação com honeypots, servindo como proxy SSHv2 transparente.
* [HoneyDrive](http://bruteforce.gr/honeydrive) - HoneyDrive é a principal distribuição Linux de honeypot.
* [Cuckoo Sandbox](http://www.cuckoosandbox.org/) - Cuckoo Sandbox é um software Open Source para análise automatizada de arquivos suspeitos.
* [T-Pot Honeypot Distro](http://dtag-dev-sec.github.io/mediator/feature/2017/11/07/t-pot-17.10.html) - T-Pot é baseado no instalador de rede do Ubuntu Server. [T-Pot Autoinstall](https://github.com/dtag-dev-sec/t-pot-autoinstall) permite instalar automaticamente.
